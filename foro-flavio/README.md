# Contagem regressiva — Flávio Bolsonaro

Site estático independente, sem servidor, anúncios, cookies ou coleta de dados. Marca a data de **01/02/2027 às 00h (UTC−03:00)**, quando termina o mandato parlamentar em 31/01/2027.

## Publicar
Este projeto foi adicionado a `foro-flavio/` do repositório `lamorimsite` para **não alterar as páginas já existentes**. Para disponibilizá-lo em `https://lamorimverso.github.io/lamorimsite/foro-flavio/`, ative GitHub Pages em **Settings → Pages → Deploy from a branch → main → /(root) → Save** (caso ainda não esteja ativo).

## Alterar o endereço
- A parte `/foro-flavio/` corresponde ao nome da pasta. Altere/mova essa pasta para modificar o caminho.
- A parte `/lamorimsite/` é o repositório. Renomeá-lo muda outros caminhos e pode prejudicar páginas existentes: **evite**.
- Para endereço curto, registre um domínio próprio e configure **Settings → Pages → Custom domain** e os registros DNS no provedor.

## Alterar a data
Edite em `index.html` a constante `end`, a data exibida e a descrição, com base em informação oficial.

**Importante:** O fim do mandato não implica automaticamente perda da competência do STF em todos os processos. Veja a [decisão do STF de 2025](https://noticias.stf.jus.br/postsnoticias/acoes-contra-autoridades-permanecem-no-stf-mesmo-apos-saida-do-cargo/).
